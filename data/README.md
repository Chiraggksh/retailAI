# Northstar Retail Support — Synthetic Assignment Data

All content is synthetic, created for an educational proof of concept. It is not a real retailer's policy or customer data.

## Contents
- `documents/`: three policy PDFs (returns, shipping, refunds)
- `operational_data/orders.csv`: synthetic order records
- `operational_data/customers.json`: synthetic demo identities
- `operational_data/returns.json`: synthetic return records
- `operational_data/refunds.json`: synthetic refund records
- `evaluation/evaluation_cases.json`: knowledge, multi-step and exception test cases
- `manifest.json`: provenance, source inventory and implementation notes
